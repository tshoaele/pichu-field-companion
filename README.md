# Pichu Field Companion

A small, installable web companion that runs as a static site.

## Publish with GitHub Pages

1. Push this folder to a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**, then choose `main` and `/ (root)`.
4. When GitHub Pages finishes publishing, open the provided HTTPS URL on your phone and add it to the Home Screen.

The page stores pet progress in the browser on each device. Weather requests require location permission and internet access.
